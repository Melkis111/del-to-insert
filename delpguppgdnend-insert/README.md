# delpguppgdnend-insert

Глобальный ремаппер клавиш **Del / PgUp / PgDn / End → Insert** для Windows 10/11 x64.
Маленький нативный exe без зависимостей: низкоуровневый хук клавиатуры (`WH_KEYBOARD_LL`),
исходная клавиша блокируется и сразу отправляется как `Insert` (E0 52). Без polling, без
AutoHotkey, без фоновых таймеров — событие обрабатывается один раз в хуке.

> [!WARNING]
> **Античиты и баны.** Глобальные низкоуровневые хуки клавиатуры и инжект ввода через
> `SendInput` — типичный признак подозрительной активности для kernel-античитов
> (Vanguard, FACEIT, ESEA, EAC, BattlEye, Ricochet и т.п.). Использование в онлайн-играх
> с таким античитом может привести к блокировке аккаунта, в том числе за «макросы/стороннее
> ПО». Инструмент предназначен для одиночных игр, собственных утилит и личных задач.
> Используешь в игре с античитом — исключительно на свой риск; автор ответственности
> за баны и нарушения ToS не несёт.

## Возможности

- Выбор при запуске, какая клавиша (или все четыре) уходит в `Insert`.
- Глобально на всю сессию: работает в любой программе, фокус не важен.
- Корректный автоповтор и отпускание: down/up сохраняют парность, модификаторы не ломаются.
- Оригинальная клавиша не «утекает»: в том числе в Raw Input (проверено самотестом),
  поэтому приложения и игры, читающие raw input, видят только `Insert`.
- Минимальный вес: статическая сборка (/MT /O1), ~140 КБ, RAM ~3–4 МБ.
- Встроенный самотест и режим лога.

## Сборка

Нужны Visual Studio 2022 (C++ build tools) или Build Tools. Сам рантайм не нужен —
exe статический.

```bat
build.cmd
```

Скрипт сам находит VS через `vswhere`. Ручная сборка:

```bat
cl /nologo /O1 /MT /W3 src\remap.c /link /OUT:remap.exe
```

## Использование

```bat
remap.cmd                 :: меню: 1=Del 2=PgUp 3=PgDn 4=End 5=все
remap.exe del             :: только Del -> Insert
remap.exe pgup pgdn end   :: любые комбинации
remap.exe del pgup pgdn end -test   :: самотест (4/4 OK + pass-through)
remap.exe del -log        :: печатать каждое перехваченное событие
```

Остановка — `Ctrl+C` в окне консоли или `taskkill /IM remap.exe /F`.

Примечания:

- Если целевое приложение запущено от администратора, ремаппер тоже нужно запускать от
  администратора (иначе хук на него не действует).
- Античиты уровня Vanguard могут блокировать или детектить LL-хуки — см. предупреждение выше.

## Как это работает

1. `SetWindowsHookExW(WH_KEYBOARD_LL, ...)` — низкоуровневый хук, единственная точка
   перехвата в глобальном масштабе без драйверов.
2. Исходная клавиша (Del/PgUp/PgDn/End) глушится (`return 1`) и в том же обработчике
   отправляется `Insert` (VK 0x2D, scan 0x52, extended) через `SendInput` с тем же
   up/down-состоянием.
3. Почему не подмена `vkCode` прямо в структуре хука (нулевой оверхед): проверено — система
   её игнорирует, Raw Input продолжает видеть оригинальный VK. Поэтому схема
   «block + reinject» — та же, что использует AutoHotkey; лишний проход очереди ввода,
   задержка доли миллисекунды.
